KyvoraPvp

KyvoraPvp is an independent Windows launcher project for Minecraft: Java Edition 1.8.9.

It is intended for players who own Minecraft: Java Edition and uses Microsoft sign-in to authenticate their account and launch the game.

KyvoraPvp does not collect Microsoft passwords or provide offline or cracked access.

This project is not affiliated with, endorsed by, or associated with Mojang or Microsoft.
